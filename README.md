# Tiny Farm, Big Moon

A cute one-screen farm game for phones (portrait, one thumb). Tap to plant, swipe a whole row to harvest, and chain crops for Bumper and MEGA BUMPER bonuses. A giant, friendly moon watches from the sky.

**These are test builds.** It's not finished.

- **Stage 1 (newest):** one 3-minute spring season on a 3x3 field (upgradable to 4x4), 6 spring crops, Pip the chick, swipe chains, Bumper and MEGA BUMPER, and the Farm Stand with 3 upgrades.

- Play: https://jweiland1978.github.io/tiny-farm/
- Stage 1 build: `/stage1/`

## Made with AI

This game was made with AI using Grok Build. Design and tuning by Jeff (BlueWater78). All art and sound are generated in code.

## Running locally

Serve the folder with any static web server, for example `python3 -m http.server`, then open `/stage1/`.
